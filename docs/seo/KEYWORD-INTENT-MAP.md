# Farsio SEO 2026 — Keyword & Search Intent Map

Tracking Issue: #8

## Principles

This map assigns one primary search intent to one canonical landing page.

Rules:

- no keyword stuffing
- no duplicate landing pages for the same intent
- no doorway pages
- Persian and English pages are localized equivalents, not literal keyword copies
- brand, product, informational and transactional intents remain distinct
- content must answer the query before attempting to rank for it

## Content expansion roadmap

Future content should be created only where search intent requires a genuinely useful standalone resource.

Priority candidates:

1. What is a Persian AI assistant?
2. Finglish to Persian correction guide
3. Persian keyboard layout recovery guide
4. Persian text-to-speech guide
5. Persian AI writing workflow
6. Persian web reading and summarization guide

Each future resource must:

- provide original practical information
- link naturally to the relevant product
- avoid duplicating product landing-page intent
- have a single canonical URL
- have FA and EN equivalents only when both versions provide real localized value
