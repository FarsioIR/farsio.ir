# Farsio.ir v0.1

Fast multilingual product-site scaffold inspired by the **information architecture** of AB Download Manager, with an original Farsio visual identity.

## Stack
- React 19
- Vite 8
- TypeScript 6
- Tailwind CSS 4
- React Router 7
- Iconify

## Languages
- Persian / RTL
- English
- Turkish

## Routes
- `/fa`, `/en`, `/tr`
- `/:lang/products/neveshtyar`
- `/:lang/products/ava`
- `/:lang/docs`
- `/:lang/about`

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

Cloudflare Pages:
- build: `npm run build`
- output: `dist`

The site includes a sticky header, theme switcher, language switcher, hero CTAs, product showcases, feature grid, Help Center CTA, docs layout, responsive design, and product GitHub links.
